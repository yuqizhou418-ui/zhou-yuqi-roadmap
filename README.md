# 原点

写下任务或理想。原点用第一性原理把它拆开：思维导图、长期大局、短期攻杀，以及今天就能勾选的行动。

页面是纯静态文件，没有构建步骤。GitHub Pages 从仓库根目录发布即可。

## 怎么用

1. 在首页「任务或理想」里写下要抵达的状态，按「拆开」（或 Enter）。
2. 推演大约四秒：澄清本质、剥去假设、找到原子、分出大局与攻杀、排入每日。可以跳过。
3. 中央是可展开的思维导图，点一枚棋子打开下一层。左侧是长期大局，右下是短期攻杀，底部是每日行动。
4. 勾选只留在这台浏览器。近期目标可以再次打开。改字之后可以重新拆解。
5. 「示例」会跑一个通用的职业目标，方便试用。

右上角「声」是一段浏览器现场生成的低音铺底，默认关闭，点一下才响。系统开启「减少动态效果」时，推演动画会直接跳到结果。

「关于方法」写着这套拆法：第一性原理、围棋里的大局观与攻杀、每日复利。

## 可选的云端接口

右上角「接口」。可以填写 OpenAI 兼容的 Base URL、密钥和模型名，只存在本机 `localStorage`，不会进这个仓库。

留空则始终使用本机引擎，可以离线。浏览器会直接请求那个地址，所以接口需要允许网页跨域。请求失败或返回无法解析时，自动改用本机结果。

## 本机数据

| 键 | 内容 |
| --- | --- |
| `yuandian-recent-v1` | 最近八个目标及其拆解 |
| `yuandian-checks-v1` | 每日行动的勾选 |
| `yuandian-llm-v1` | 可选接口的地址、密钥、模型 |

清掉站点数据，这些记录就没有了。不会上传。

## 文件

| 路径 | 作用 |
| --- | --- |
| `index.html` | 页面 |
| `styles.css` | 样式 |
| `engine.js` | 离线第一性原理引擎 |
| `app.js` | 交互、动画、声音、可选云端 |
| `favicon.svg` | 图标 |
| `.nojekyll` | 让 GitHub Pages 按原样提供文件 |
| `test/engine.test.js` | 引擎测试，不参与页面 |
| `fde/` | 与原点无关的内部草案，首页没有入口 |

## 本地预览

在仓库根目录：

```bash
python3 -m http.server 8742
```

打开 [http://127.0.0.1:8742](http://127.0.0.1:8742)。

引擎测试：

```bash
node --test test/engine.test.js
```

## 发布

仓库 Settings → Pages → Deploy from a branch。分支选 `main`，文件夹选 `/ (root)`。站点在 `https://<用户名>.github.io/<仓库名>/`。

不要把密钥、token 或 `.env` 放进这个仓库。
