# 周煜淇 · 发展路线图

这是周煜淇（Louis & Fly）的个人发展路线图打卡站：近 → 中 → 远，目标是创办并带领一家科技公司登陆美股。

**本仓库是这份站点的长期唯一源头。** 文案、课表节奏、打卡逻辑的后续修改，都改这里的文件，再重新发布。不要另存一份「临时版」当正式站。

## 站点做什么

- 按澳门时间与课表，给出当天的深工窗口和打卡清单（语言、健身、外贸实习、阅读、日记、创业轻量）。
- 首页进度环、连续打卡天数、本周活跃日、近 7 日轨迹。
- 近 / 中 / 远路线、一周节奏、本周为什么重要、个人燃料。
- 界面以中文为主；顶栏 EN 只切换首屏导语。

页面是纯静态文件，没有后端、没有账号、没有构建步骤。

## 文件

| 路径 | 作用 |
| --- | --- |
| `index.html` | 页面结构与中文文案 |
| `styles.css` | 样式 |
| `script.js` | 打卡、进度环、周节奏、庆祝动画 |
| `favicon.svg` | 站点图标（沿用页面里的飞机标记，不是照片） |
| `.nojekyll` | 告诉 GitHub Pages 不要用 Jekyll 处理这个仓库 |
| `fde/` | 内部草案：企业 FDE 落地页。未锁参，勿外发，不在首页放入口 |

资源都用相对路径（`styles.css`、`script.js`），放在仓库根目录即可被 GitHub Pages 或任意静态托管直接打开。

## 本地预览

在仓库根目录任选一种：

```bash
# Python 3（推荐）
python3 -m http.server 8742

# 已安装 Node 时
npx --yes serve -l 8742 .
```

浏览器打开 [http://127.0.0.1:8742](http://127.0.0.1:8742)。

也可以直接双击打开 `index.html`。打卡脚本不依赖服务器接口；用本地静态服务预览更接近正式托管后的效果。

## 打卡数据只在本机

勾选结果写在当前浏览器的 `localStorage`，键名是 `zhou-yuqi-roadmap-checkins-v1`。

- 不会上传，也不会出现在这个 Git 仓库里。
- 换浏览器、换设备、清站点数据，记录就没了。
- 「重置今日」只清当天。要整段清空，可在该站点的开发者工具里删除上述键。

## 怎么改、怎么发布

1. 改 `index.html`（文案与结构）、`styles.css` 或 `script.js`（课表在 `script.js` 的 `WEEK`）。
2. 用上面的本地服务看一遍今日打卡、路线图和周节奏。
3. 提交并推送到这个仓库。托管若跟踪默认分支，推上去就会更新。

## 公开托管（不需要密钥）

推荐 **GitHub Pages**，仓库已经按静态根目录准备好：

1. 把这个仓库推到 GitHub（公开仓库即可，不必配 token 给站点本身）。
2. 仓库 Settings → Pages → Build and deployment 选 **Deploy from a branch**。
3. Branch 选默认分支，文件夹选 **`/ (root)`**，保存。
4. 站点会出现在 `https://<用户名>.github.io/<仓库名>/`。根目录的 `.nojekyll` 避免 Jekyll 改写或忽略文件。

备选：**Vercel** 或 **Netlify**。导入同一个 Git 仓库，框架选 Other / 静态站点，构建命令留空，输出目录填 `.` 或仓库根。公开仓库用平台的 Git 集成即可，不必把密钥写进仓库。

不要把个人密钥、token 或 `.env` 放进这个仓库。这个站点不需要它们。

## 内部草案（勿外发）

`fde/index.html` 是企业 FDE 介绍页的内部文案草案，状态为未锁参。不要把它链到首页，也不要单独当正式营销页发布。价格、签约主体、商务联系方式、案例名和指标都还是占位；页上表单没有后端。

本地预览：把上面的静态服务开在仓库根目录，打开 [http://127.0.0.1:8742/fde/](http://127.0.0.1:8742/fde/)。
