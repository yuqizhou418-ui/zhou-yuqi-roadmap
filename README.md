# 原点

先写下想达成的目标，和你给它的时间。进入之后，看思维导图、长期大局、短期攻杀，以及可以勾选的每日行动。

时间用你写下的原文，页面不另排一套日期。页面是纯静态文件。GitHub Pages 从仓库根目录发布即可。

## 怎么用

1. 首页只有目标和时间。
2. 按「进入」。主界面中央是可点开的思维导图，左侧是长期大局，右侧是短期攻杀，底部是每日行动。
3. 勾选和最近记录只留在这台浏览器。
4. 「声」在主界面，默认关闭。

## 本机与预留接口

右上角「接口」可选 ChatGPT 或 Grok。默认地址分别是 `https://api.openai.com/v1` 与 `https://api.x.ai/v1`，模型名可以改。密钥、地址、模型和提供方只存在本机 `localStorage`。点「测试连接」会向该地址的 `chat/completions` 发一句极短探测，密钥只放在 `Authorization` 请求头里。测通之后，进入盘面会用该模型生成导图；失败则回到本机并提示。未填密钥时只用本机，不报错。

公开的 OpenAI 与 xAI 地址常常不允许浏览器跨域。这时请把 Base URL 换成你自己允许网页访问的网关。

| 键 | 内容 |
| --- | --- |
| `yuandian-plans-v3` | 最近的目标、时间和拆解 |
| `yuandian-checks-v3` | 每日勾选 |
| `yuandian-llm-v1` | 预留的地址、密钥、模型 |
